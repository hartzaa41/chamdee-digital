# ชำดีดิจิทัล — เว็บแอปต้นแบบ

เว็บแอปต้นแบบสำหรับร้านตายาย ใช้บันทึกยอดขาย ดูยอดรวม และติดตามสต็อกสินค้า

## จุดสำคัญ

- ไม่ต้องติดตั้งแอป เปิดผ่านเว็บเบราว์เซอร์ได้
- Responsive ใช้ได้ทั้งโทรศัพท์และคอมพิวเตอร์
- ข้อมูลตัวอย่างและรายการที่กรอกเก็บใน `localStorage` ของเบราว์เซอร์
- ไม่มี backend, login, payment หรือ API ที่ต้องเสียเงิน
- มี Dashboard, บันทึกยอดขาย และสต็อกสินค้า

## ทดลองในเครื่อง

วิธีเร็วที่สุด: เปิด `index.html` ด้วย Chrome/Edge ได้เลย

ถ้าต้องการใช้ local server ให้เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```bash
python3 -m http.server 3000
```

จากนั้นเปิด `http://localhost:3000`

## นำขึ้นอินเทอร์เน็ตแบบไม่ต้องติดตั้ง

ต้องอัปโหลดไฟล์ชุดนี้ขึ้นบริการโฮสต์แบบ static จึงจะได้ลิงก์สาธารณะ เช่น:

- **GitHub Pages**: สร้าง repository ใหม่ อัปโหลดไฟล์ทั้งหมดไว้ที่ root แล้วไปที่ Settings → Pages → Deploy from branch → `main` / root
- **Netlify Drop**: ลากโฟลเดอร์โปรเจกต์ไปวางที่หน้า Netlify Drop แล้วคัดลอก URL ที่ได้
- **Vercel**: Import repository หรืออัปโหลดโฟลเดอร์เป็น static project

บริการเหล่านี้มี free tier สำหรับเว็บ static แต่เงื่อนไขอาจเปลี่ยนได้ ควรตรวจสอบหน้าราคา/เงื่อนไขล่าสุดของผู้ให้บริการก่อนใช้งานจริง

## หมายเหตุเรื่องข้อมูล

ข้อมูลเก็บเฉพาะในเบราว์เซอร์ของอุปกรณ์นั้น ๆ ถ้าเปิดคนละโทรศัพท์ ข้อมูลจะไม่เหมือนกัน และถ้าล้าง site data ข้อมูลอาจหาย เหมาะกับ Prototype และการสาธิตในชั้นเรียน หากใช้งานจริงควรเพิ่มฐานข้อมูลและระบบสำรองข้อมูลภายหลัง

## เดโมหน้าห้อง

1. เปิด Dashboard
2. ไปที่ “บันทึกยอดขาย”
3. เลือกสินค้าและกรอกจำนวน
4. กดบันทึก
5. กลับไปดูยอดขายและสต็อกที่อัปเดต
6. เปิด “สต็อกสินค้า” แล้วกด “เพิ่มสินค้าเข้า” เพื่อสาธิต
